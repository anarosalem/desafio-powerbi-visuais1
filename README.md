# Desafio Power BI: Criando Visuais e Relatórios 📊

## Objetivo
Este repositório contém a entrega do desafio de Power BI da DIO. O objetivo principal foi treinar a criação e disposição de visuais, modificação de títulos e dicas de ferramentas.

## O que foi desenvolvido
1. **Páginas 1 e 2:** Replicação dos relatórios propostos no curso utilizando a base de dados "Financials" (sample).
2. **Página 3 (Desafio Prático):** Criação de uma página focada em análise geográfica e de segmentação contendo:
   - **Mapa 1:** Soma de Vendas (Sales) e Unidades Vendidas (Units Sold) por País.
   - **Mapa 2:** Soma de Lucro (Profit) por País.
   - **Gráfico de Pizza:** Lucro (Profit) por Segmento.

## Ajustes Realizados
- ✔️ Disposição dos visuais organizada para facilitar a leitura.
- ✔️ Nomes dos visuais alterados para termos claros e diretos de acordo com o contexto (ex: "Lucro por Segmento").
- ✔️ Validação dos campos utilizados nas dicas de ferramentas (Tooltips).
- ✔️ **Nota sobre a entrega:** Conforme as instruções do desafio, como não possuo a licença do Microsoft PowerPoint, pulei a etapa de suplemento e o relatório final foi salvo e anexado diretamente neste repositório.

## Como acessar
O projeto completo pode ser acessado baixando o arquivo `Desafio_PowerBI.pbix` contido na raiz deste repositório e abrindo-o no Power BI Desktop.
